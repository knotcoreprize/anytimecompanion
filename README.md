## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **No Restrictions** | Bring any companion into any area including story missions |
| **Castle Access** | Have companions follow you through Hogwarts hallways and classes |
| **Combat Support** | Companions fight alongside you everywhere in the game |
| **Easy Toggle** | Enable or disable per-companion with a simple hotkey |
